Seller-facing UI for managing the orders that belong to them: list of their sub-orders with filter, detail with forward-only status advancement controls, optional tracking number prompt at SHIPPED, and seller-only cancel (pre-SHIPPED) that triggers Stripe partial refund via the `cancelSellerOrder` callable from 06-01. Reuses OrderStatusBadge and OrderStatusStepper from 06-02.

Purpose: Implements ORDR-06 (forward-only advancement), ORDR-07 (cancel pre-SHIPPED), and ORDR-08 (tracking prompt at SHIPPED) per CONTEXT D3 + D6. Defense-in-depth: UI gates buttons by `status.allowedNext()`; Firestore rules + callable from 06-01 are the actual security boundary.

Output: Two screens + ViewModels + States/Actions; two dialogs; SellerTab Orders tab wired; navigation routes; ViewModel + Compose tests.
</objective>
